Video Downloader - Windows EXE build

1. Install Python 3.12 or newer on Windows.
2. Put ffmpeg.exe and ffprobe.exe into this folder:
   ffmpeg\ffmpeg.exe
   ffmpeg\ffprobe.exe
3. Double-click build_exe.bat.
4. The finished files are in dist\
   dist\VideoDownloader.exe
   dist\ffmpeg\ffmpeg.exe
   dist\ffmpeg\ffprobe.exe

The application uses yt-dlp and requires you to comply with the terms of the video service and copyright law. Download only content you are authorized to download.
